O que é Python?

Python é uma linguagem de programação de alto nível, interpretada e de propósito geral. Criada por Guido van Rossum no início dos anos 90, sua filosofia foca na legibilidade do código e na simplicidade.

Para que serve?

Diferente de algumas linguagens que são nichadas, o Python é como um "canivete suíço":

  • Data Science e IA: É a linguagem número 1 para análise de dados e aprendizado de máquina.
  • Desenvolvimento Web: Através de frameworks como Django e Flask.
  • Automação e Scripting: Criar robôs para tarefas repetitivas (planilhas, e-mails, web scraping).
  • Desenvolvimento de Software: Ferramentas de desktop e testes automatizados.

Vantagens na vida Profissional

  • Curva de Aprendizado Suave: A sintaxe é muito próxima do inglês, o que facilita o aprendizado rápido.
  • Alta Empregabilidade: Praticamente todas as grandes empresas (Google, Netflix, Instagram) utilizam Python.
  • Comunidade Gigante: Se você tiver um problema, alguém já resolveu e postou a solução na internet.
  • Salários Atrativos: Especialistas em Python, especialmente em dados e IA, estão entre os profissionais mais bem pagos do setor tech.

Programação Orientada a Objeto(POO)

A POO é um paradigma de programação, ou seja, uma forma de pensar e organizar o seu código.

O conceito

Em vez de focar apenas em funções e lógica sequencial, a POO organiza o software em torno de "Objetos". Imagine que você quer programar um sistema para um petshop:

  • Classe: É o "molde" ou a planta baixa (Ex: A classe Cachorro).
  • Objeto: É a instância real criada a partir do molde (Ex: O cachorro "Bobi", que tem nome, idade e cor).

Os quatro pilares principais da POO são:

  1. Abstração: Isolar o que é essencial (esconder a complexidade).
  2. Encapsulamento: Proteger os dados dentro do objeto.
  3. Herança: Criar novas classes baseadas em classes existentes (Ex: Cachorro herda de Animal).
  4. Polimorfismo: Permitir que diferentes objetos respondam à mesma mensagem de formas diferentes.

Vantagens de utilizar POO

  • Reutilização de Código:Você escreve uma classe uma vez e a utiliza em vários lugares do projeto.
  • Organização e Escalabilidade:Fica muito mais fácil gerenciar projetos grandes e complexos.
  • Manutenção Facilitada:Se um erro ocorre no comportamento do "Cachorro", você sabe exatamente onde mexer, sem quebrar o resto do sistema.
  • Trabalho em Equipe:Diferentes programadores podem trabalhar em diferentes objetos simultaneamente sem interferências.
